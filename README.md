# moex-crisis-prediction
This project investigates the prediction of crisis periods on the Moscow Exchange (MOEX) index using machine learning methods.

The study combines financial time series, macroeconomic indicators, and market volatility measures to forecast crisis events and evaluate the importance of different explanatory factors.

The project focuses on:
- crisis detection and prediction,
- feature engineering for financial time series,
- interpretable machine learning,
- analysis of macroeconomic and market factors.
